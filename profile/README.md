# 👋 Welcome to FameTech202x

> **Extending, automating, and optimizing industry-standard creative and CAD software.**

At **FameTech202x**, we build custom plugins, scripts, extensions, and workflow automation tools for technical and design software—including Adobe Illustrator, AutoCAD, and similar industry applications. Our goal is to eliminate repetitive tasks, bridge software gaps, and empower designers, drafters, and engineers to work faster and smarter.

---

### 🛠️ What We Build & Modify

- **CAD Automation & Extensions:** Custom AutoLISP routines, .NET / C# plugins, and Python scripts for AutoCAD and related drafting platforms.
- **Creative Suite Scripting:** ExtendScript (JSX), UXP plugins, and batch-processing tools for Adobe Illustrator and vector workflows.
- **Workflow Bridges:** Tools that streamline file conversion, layer management, and data exchange between CAD and vector illustration environments.
- **UI/UX Enhancements:** Custom panels, hotkeys, and macro setups tailored for high-efficiency production environments.

---

### 📂 Featured Repositories

- **`illustrator-batch-tools`** – Automated path cleanup, artboard organization, and export scripts for Adobe Illustrator.
- **`autocad-workflow-kit`** – Custom AutoLISP and C# utilities for rapid layer standardization, block management, and title-block automation.
- **`cad-to-vector-bridge`** – Precision formatting scripts to prepare DWG/DXF exports seamlessly for vector illustration.

---

### 🚀 Getting Started

To use our tools, browse our repositories and check each project's individual `README.md` for installation instructions (such as loading `.lsp` files in AutoCAD via `APPLOAD` or placing `.jsx` scripts into Illustrator's `Presets/Scripts` folder).
